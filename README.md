# Botanica

Botanica merupakan aplikasi simulasi siklus kehidupan tumbuhan berbasis Python dan Tkinter. Aplikasi ini menampilkan proses pertumbuhan tumbuhan melalui animasi interaktif dengan ilustrasi alam dan tampilan yang minimalis.

## Fitur

- Animasi siklus kehidupan tumbuhan secara otomatis
- Visualisasi pertumbuhan akar, batang, daun, bunga, dan biji
- Label bagian tumbuhan dengan tanda panah
- Animasi lingkungan yang dinamis
- Siklus pertumbuhan berulang secara otomatis

## Teknologi

- Python
- Tkinter
- Math
- Random
- Time

## Cara Menjalankan

Pastikan Python sudah terinstal, kemudian jalankan:

```bash
python main.py
```

Tidak memerlukan instalasi library tambahan.

## Tujuan

Project ini dikembangkan sebagai media visualisasi edukatif untuk memahami siklus kehidupan tumbuhan melalui pemrograman Python dan animasi grafis
